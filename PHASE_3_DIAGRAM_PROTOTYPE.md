# Phase 3 — Diagram Prototype

## Model
The diagram is a relationship explorer, not a fit calculator.

Person-side lenses:
- Interests
- Work values
- Abilities
- Work styles

Work-side lenses:
- Activities / tasks
- Work context
- Occupation requirements
- Work values / occupational characteristics

## Interaction
Selecting a person-side lens creates a visible relationship path to the relevant work-side lens. It does not create arrows between the four person-side lenses, and it never outputs a recommendation or numeric fit score.

## Responsive transformation
Desktop: two-field spatial composition.
Mobile: sequential person → relationship → work composition.

## Accessible fallback
A semantic list describes the currently selected relationship in text.
